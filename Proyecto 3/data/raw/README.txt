===========================================================
   Bank Customer Churn Dataset - Documentation
===========================================================

1. Introduction

This dataset contains information about bank customers and whether they
have churned (left the bank). It is commonly used for binary classification
tasks to predict customer attrition in the banking sector.

The dataset simulates realistic customer behavior patterns observed in
European banking institutions.

2. Data Description

- Records: 10,000 bank customers
- Features: 14 attributes
- Target: Exited (1 = Churned, 0 = Retained)
- Class Distribution: ~20% churn rate (realistic imbalance)

Feature Dictionary:
- RowNumber: Row index
- CustomerId: Unique customer identifier
- Surname: Customer surname
- CreditScore: Credit score (300-850)
- Geography: Country (France, Spain, Germany)
- Gender: Male/Female
- Age: Customer age
- Tenure: Years as bank customer (0-10)
- Balance: Account balance
- NumOfProducts: Number of bank products used (1-4)
- HasCrCard: Has credit card (0/1)
- IsActiveMember: Active member status (0/1)
- EstimatedSalary: Estimated annual salary
- Exited: Churned (1) or Retained (0) - TARGET
